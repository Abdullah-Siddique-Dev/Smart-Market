================================================================
   HOW TO SHARE SMART MARKET OS WITH OTHER COMPUTERS
================================================================

QUICK ANSWER:
You need to give them 3 things:
1. The .exe file
2. The server folder (with all files inside)
3. The launcher script

================================================================
              STEP-BY-STEP PACKAGING GUIDE
================================================================

STEP 1: Create a Folder
-----------------------
Create a new folder called: SmartMarket-Complete

STEP 2: Copy These Files INTO That Folder
-----------------------------------------

Copy FROM your project:

1. smartmarket.exe
   Location: D:\Projects\Smart Market\src-tauri\target\release\smartmarket.exe
   Size: ~4.2 MB

2. RUN-SMARTMARKET.bat
   Location: D:\Projects\Smart Market\RUN-SMARTMARKET.bat
   Size: ~3 KB

3. server (ENTIRE FOLDER - THIS IS IMPORTANT!)
   Location: D:\Projects\Smart Market\server\
   Size: ~200 MB
   ⚠️ Must include ALL subfolders:
      - server/dist/
      - server/node_modules/ (largest folder ~200MB)
      - server/package.json
      - server/src/ (optional but recommended)

4. README-FOR-USERS.txt
   Location: D:\Projects\Smart Market\README-FOR-USERS.txt
   Size: ~5 KB

Your folder should look like this:
SmartMarket-Complete/
├── smartmarket.exe
├── RUN-SMARTMARKET.bat
├── README-FOR-USERS.txt
└── server/
    ├── dist/
    ├── node_modules/
    ├── src/
    └── package.json

STEP 3: Compress Into ZIP (Optional but Recommended)
----------------------------------------------------
1. Right-click on "SmartMarket-Complete" folder
2. Send to → Compressed (zipped) folder
3. Result: SmartMarket-Complete.zip (~100 MB)

================================================================
              HOW TO SHARE THE PACKAGE
================================================================

METHOD 1: USB Drive
------------------
Copy SmartMarket-Complete.zip to USB drive
Give USB to user
User extracts and runs RUN-SMARTMARKET.bat

METHOD 2: Cloud Storage (Google Drive, Dropbox, etc.)
----------------------------------------------------
Upload SmartMarket-Complete.zip
Share download link
User downloads, extracts, and runs RUN-SMARTMARKET.bat

METHOD 3: Local Network
-----------------------
Place folder on shared network drive
User copies to their computer
Runs RUN-SMARTMARKET.bat

================================================================
           WHAT THE OTHER COMPUTER NEEDS
================================================================

REQUIRED (User must install):
✅ Node.js 18.x or higher
   Download from: https://nodejs.org/en/download/
   Takes 5 minutes to install

OPTIONAL (Nice to have):
✅ Windows 10/11 (works on Windows 7/8 too)
✅ Modern hardware (works on any PC from last 10 years)

================================================================
              INSTRUCTIONS FOR THE USER
================================================================

Give them these simple steps:

"""

That's it! Super simple.

================================================================
                 TROUBLESHOOTING
================================================================

If user says "Login Failed":
→ Server didn't start. Check if Node.js is installed.
→ Run RUN-SMARTMARKET.bat again
→ Wait longer (10-15 seconds instead of 5)

If user says ".exe doesn't start":
→ Windows Defender might be blocking it
→ Right-click .exe → Properties → Unblock
→ Or run as Administrator

If user says "Cannot find module":
→ server/node_modules folder is missing
→ Re-copy the entire server folder

If user says "Node.js is not installed":
→ They need to install it from nodejs.org
→ Show them: https://nodejs.org/en/download/
→ Download "Windows Installer" → Run it → Restart computer

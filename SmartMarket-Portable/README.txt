========================================
  Smart Market OS v1.0.0
  Portable Edition
========================================

REQUIREMENTS:
- Windows 7/8/10/11 (64-bit)
- Node.js 18+ installed

INSTALLATION:
1. Install Node.js from https://nodejs.org if not installed
2. Double-click "START-SMARTMARKET.bat"
3. Wait for server to start (~5 seconds)
4. Application will open automatically

DEFAULT LOGIN:
- Username: admin
- Password: admin123

FILES:
- smartmarket.exe         : Frontend application
- START-SMARTMARKET.bat   : Launcher script (USE THIS)
- server/                 : Backend API
- data/                   : Database and files

TROUBLESHOOTING:
- If app doesn't start, check if Node.js is installed
- If login fails, ensure server started (check console)
- Port 4000 must be available
- Check data/logs/ for error messages

SUPPORT:
Read OPERATIONS_GUIDE.md for complete usage instructions
